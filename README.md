# 💎 CodeCrystal 

**CodeCrystal ** is a fun, beginner-friendly browser game where you learn basic Python by completing magical coding challenges.

Collect gems, unlock new levels, and help Byte the wizard bring light back to the kingdom—one line of Python at a time.

## 🎮 Play the game

Open `index.html` in a browser, or use the live game link once GitHub Pages is enabled.

## ✨ Features

- 15 beginner-friendly Python coding levels
- Challenges that become harder little by little
- Helpful hints for every level
- Clear explanations when an answer is incorrect
- The correct answer is shown so players can learn from mistakes
- Gem rewards for completing levels
- Unlockable level path and progress bar
- Progress saved in the browser
- Smooth, responsive design for desktop and mobile

## 🐍 What you can learn

| Level range | Python skill |
| --- | --- |
| 1–4 | `print()`, text, variables, and `input()` |
| 5–7 | Numbers, arithmetic, `if` statements, and comparisons |
| 8–9 | `for` loops and `while` loops |
| 10–11 | Lists and `append()` |
| 12–14 | Functions, dictionaries, and parameters |
| 15 | Combining loops, conditions, and dictionaries |

## 🕹️ How to play

1. Read the story and coding challenge.
2. Write the requested Python code in the editor.
3. Press **Run code**.
4. If your code is correct, earn 💎 gems and unlock the next level.
5. If it is not correct, read the explanation, study the correct code, and try again.

## 🚀 Run the game locally

1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Install the free **Live Server** extension.
4. Right-click `index.html` and select **Open with Live Server**.

You can also open `index.html` directly in a browser.
